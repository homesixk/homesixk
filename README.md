## WHO I AM

I'm Hammad Ali — a backend developer who'd rather spend an extra hour on the data model than debug it in production six months later. I like the unglamorous half of software: the API that doesn't buckle under load, the migration that doesn't lock the table, the schema that still makes sense a year in.

A few things that describe how I work:

- I design for the failure case first, the happy path second
- I'd rather delete a workaround than build on top of it
- I care more about a system holding up than a demo looking good
- I rebuild my own portfolio more often than most people update a resume
